Tutorial

This tutorial works through S2Geography.jl using real country boundaries from NaturalEarth.jl.

Loading data

using S2Geography
import GeoInterface as GI
using NaturalEarth

countries = naturalearth("admin_0_countries", 110)

Pick out a few countries by name:

names = countries.NAME
idx(name) = findfirst(==(name), names)

germany = Geography(countries.geometry[idx("Germany")])
france  = Geography(countries.geometry[idx("France")])
brazil  = Geography(countries.geometry[idx("Brazil")])

Geography accepts any GeoInterface-compatible geometry. GI.convert(Geography, geom) does the same thing, and WKT and WKB work too:

berlin = Geography("POINT (13.405 52.52)")
paris  = Geography("POINT (2.3522 48.8566)")

Spatial predicates

Do Germany and France share a border?

intersects(germany, france)
true
intersects(germany, brazil)
false

Is Berlin in Germany?

contains(germany, berlin)
true

within is the converse of contains, and disjoint the complement of intersects:

within(berlin, germany), disjoint(germany, brazil)
(true, true)

Measurements

All measures are in SI units: metres for lengths, square metres for areas. No conversion factor is needed.

d = distance(berlin, paris)
println("Berlin to Paris: $(round(d / 1000, digits=1)) km")
Berlin to Paris: 877.5 km
a = area(germany)
println("Germany: $(round(a / 1e6, digits=0)) km²")
Germany: 356134.0 km²

distance measures the shortest separation between two geographies, so a point inside a polygon is zero metres away from it:

distance(germany, berlin)
0.0

The perimeter of Germany's boundary, and the great-circle distance between its two furthest-apart points:

println("Perimeter: $(round(perimeter(germany) / 1000, digits=0)) km")
println("Furthest:  $(round(max_distance(germany, germany) / 1000, digits=0)) km")
Perimeter: 2999.0 km
Furthest:  888.0 km

Working in batches

Every operation accepts vectors as well as single geographies, and evaluates them in one pass through the underlying library. Scalar arguments broadcast against vector ones.

all_countries = Geography.(countries.geometry)
areas = area(all_countries)
order = sortperm(areas; rev=true)
[names[i] => round(areas[i] / 1e6, digits=0) for i in order[1:5]]
5-element Vector{Pair{String, Float64}}:
                   "Russia" => 1.6924373e7
               "Antarctica" => 1.2236257e7
                   "Canada" => 9.984404e6
 "United States of America" => 9.494305e6
                    "China" => 9.408029e6

Which countries does a point in the North Sea fall closest to?

buoy = Geography("POINT (3.0 56.0)")
d = distance(all_countries, buoy)
[names[i] => round(d[i] / 1000, digits=1) for i in sortperm(d)[1:5]]
5-element Vector{Pair{String, Float64}}:
 "United Kingdom" => 276.5
        "Denmark" => 317.0
         "Norway" => 328.4
    "Netherlands" => 336.8
        "Germany" => 366.7

Batching is what makes this practical — one call over 177 countries rather than 177 separate calls.

Boolean operations

shared = intersection(germany, france)
println("Shared border region: $(round(area(shared) / 1e6, digits=2)) km²")
Shared border region: 0.0 km²
both = union(germany, france)
round(area(both) / 1e6, digits=0)
999926.0

Areas obey inclusion–exclusion, on the sphere just as in the plane:

area(union(germany, france)) ≈
    area(germany) + area(france) - area(intersection(germany, france))
true

Derived geometries

c = centroid(germany)
println("Centroid: ($(round(GI.x(c), digits=2))°, $(round(GI.y(c), digits=2))°)")
Centroid: (10.27°, 51.08°)

point_on_surface is guaranteed to lie inside the geometry, which a centroid is not:

contains(germany, point_on_surface(germany))
true

boundary returns the outline as lines, and convex_hull the smallest convex region containing the input:

outline = boundary(germany)
GI.geomtrait(outline), arclength(outline) ≈ perimeter(germany)
(GeoInterface.MultiLineStringTrait(), true)
hull = convex_hull(germany)
round(area(hull) / area(germany), digits=3)   # how far from convex Germany is
1.193

Transformations

simplify removes vertices that lie within a tolerance (in metres) of the simplified path:

coarse = simplify(germany, 10_000)   # 10 km tolerance
println("Simplified area is within $(round(100 * abs(area(coarse) / area(germany) - 1), digits=2))% of the original")
Simplified area is within 0.32% of the original

buffer grows a geometry by a distance in metres:

grown = buffer(berlin, 50_000)      # 50 km disc around Berlin
round(area(grown) / 1e6, digits=0)  # ≈ π × 50²
7804.0

segmentize densifies long edges so they can be drawn as straight lines in a projected plot without visibly departing from the true geodesic:

long_edge = Geography("LINESTRING (-100 40, 20 50)")
GI.ngeom(long_edge), GI.ngeom(segmentize(long_edge, 100_000))
(0x00000002, 0x00000056)

Linear referencing

route = Geography("LINESTRING (2.3522 48.8566, 13.405 52.52)")
halfway = line_interpolate_point(route, 0.5)
println("Halfway: ($(round(GI.x(halfway), digits=3))°, $(round(GI.y(halfway), digits=3))°)")
Halfway: (7.662°, 50.819°)
line_locate_point(route, halfway)
0.4999999999999996

Bounding boxes

GeoInterface.extent computes the bounding box on the sphere, so it accounts for the curvature of geodesic edges. A line along the 45th parallel bulges polewards, and the box reflects that:

GI.extent(Geography("LINESTRING (-45 45, 45 45)"))
Extent(X = (-45.0, 45.0), Y = (44.99999999999997, 54.7356103172454))

A planar library would report Y = (45.0, 45.0) here, which is wrong: the shortest path between those endpoints genuinely passes north of 54°.

GI.extent(germany)
Extent(X = (5.9886579513549805, 15.016996383666994), Y = (47.30248641967771, 54.98310470581057))

S2 cells

S2 covers the sphere with a hierarchy of cells. cellid gives the leaf cell containing a point, and covering gives a set of cells that together contain a geometry — the basis for spatial indexing and joins.

cellid(berlin)
0x47a851dfecc9a86d
cells = covering(germany)
length(cells)
8
covering(germany, 0, 8, 4)   # min level 0, max level 8, at most 4 cells
4-element reinterpret(UInt64, ::Vector{Int64}):
 0x4707000000000000
 0x470c000000000000
 0x4774000000000000
 0x47c0000000000000
